# 🚀 Quick Start Guide

## Get Started in 3 Steps

### Step 1: Install Dependencies
```bash
pip install -r requirements.txt
```

### Step 2: Run the Application
```bash
streamlit run streamlit_app.py
```

### Step 3: Use the Tool
1. Open your browser to `http://localhost:8501`
2. Enter your OpenAI API key in the sidebar
3. Paste your job description
4. Click "Generate Bullet Points"
5. Download your results!

## 🎯 What This Tool Does

This AI-powered application generates **20 tailored resume bullet points** from any job description using advanced cognitive frameworks:

- 🧠 **Skeleton of Thoughts**: Maps job requirements
- 🌳 **Tree of Thoughts**: Analyzes connections
- ⛓️ **Chain-of-Thought**: Refines for impact

## ✨ Key Benefits

✅ **80%+ Keyword Match** - Automatically validated  
✅ **Unique Action Verbs** - No repetition  
✅ **Quantified Results** - Metrics in every bullet  
✅ **Achievement-Focused** - Not just duties  
✅ **ATS-Optimized** - Keyword-rich content
